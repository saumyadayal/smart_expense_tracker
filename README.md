#  Smart Expense Tracker (Java)

##  Overview

Smart Expense Tracker is a Java-based console application that helps users manage their daily expenses efficiently. It allows users to record transactions, categorize spending, and generate insightful reports to improve financial habits.

This project showcases strong use of **Object-Oriented Programming (OOP)**, **data structures**, and **file handling** in Java.

---

##  Features

*  Add daily expenses (amount, category, date, description)
*  Categorize expenses (Food, Travel, Shopping, etc.)
*  View total spending
*  Category-wise expense report
* Smart Summary with insights
*  Spending alerts based on category usage
*  Data persistence using file handling

---

## Smart Insights (Highlight Feature)

* Shows highest spending category
* Calculates percentage distribution of expenses
* Warns if spending exceeds 50% in one category
* Suggests better financial habits

---

## 🛠️ Tech Stack

* **Language:** Java
* **Concepts Used:**

  * Object-Oriented Programming (OOP)
  * ArrayList & HashMap
  * File Handling (BufferedReader, BufferedWriter)
